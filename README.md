# Data Engineer - Senior

## Definition
Diseña la arquitectura de datos (Lakehouse, Data Mesh), implementa gobierno de datos (lineage, calidad, catálogo), configura streaming en tiempo real (Kafka, Flink) y automatiza la infraestructura de datos con IaC.

## Specific Project
Plataforma de análisis en tiempo real (Kafka + Flink) para clicks de 1M usuarios/minuto, integrada en un Data Mesh federado con gobernanza centralizada.

## Core Concepts
Apache Flink (windowing, event time, watermarks), Kafka (topics, particiones, consumer groups), Data Mesh (dominios descentralizados, contratos de datos), Apache Iceberg (tablas con evolución de esquema), Data Lineage (OpenLineage/Marquez), IaC con Terraform para clusters de datos.

## Recommended Modern Technologies
Apache Flink (streaming con SQL y DataStream API) o RisingWave, Apache Iceberg (catálogo REST) + Trino, Databricks Unity Catalog, OpenLineage, Meltano, Polars en modo streaming.
