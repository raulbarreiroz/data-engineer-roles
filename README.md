# Data Engineer - Semi Senior

## Definition
Orquesta flujos complejos con Airflow, procesa volúmenes masivos con Spark (batch), optimiza particionado en Data Lakes y escribe consultas eficientes en SQL analítico.

## Specific Project
Lakehouse de logs de servidores usando PySpark que procesa 500 GB de logs, aplica joins en ventanas de tiempo y escribe en Delta Lake, orquestado con Airflow.

## Core Concepts
PySpark (DataFrames, Spark SQL, UDFs), Delta Lake (ACID y time travel), particionamiento dinámico (por fecha), optimización de shuffle (repartición y broadcasting), Airflow (XComs, Task Groups), almacenamiento en S3/GCS con roles IAM.

## Recommended Modern Technologies
PySpark (sobre Databricks o EMR Serverless), dbt Core, Delta Lake 3, Airflow con Astro SDK, AWS Glue / Azure Data Factory, Great Expectations.
