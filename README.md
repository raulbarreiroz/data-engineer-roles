# Data Engineer - Junior

## Definition
Construye pipelines ETL/ELT sencillos con herramientas visuales (SSIS) o código básico (Pandas). Extrae datos de fuentes estructuradas y los carga en data warehouses.

## Specific Project
ETL diario que extrae ventas de un CSV/API pública, limpia nulos y duplicados con Pandas, y carga el resultado en una tabla PostgreSQL.

## Core Concepts
Python (Pandas - read_csv, dropna, merge), SQL básico (INSERT, UPDATE), programación con Cron o Airflow (DAG sencillo), formatos Parquet/CSV, contenedores Docker básicos (Dockerfile).

## Recommended Modern Technologies
Python con Pandas 2 y Polars (DataFrames rápidos), dlt (extracción ELT simple), DuckDB, Apache Airflow 2 (DAGs básicos con TaskFlow API), Parquet + PyArrow.
